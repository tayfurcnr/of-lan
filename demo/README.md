# Demo Assets

This folder contains screenshots and reference assets for OF-LAN documentation and presentations.

## Recommended files

- `main-screen.png` - main application layout
- `shared-area.png` - shared files view
- `chat-view.png` - direct chat example

## Usage

Use this directory for:

- README screenshots
- release notes
- onboarding material
- presentation slides

## Guidelines

- Keep filenames stable so they can be referenced from documentation.
- Prefer PNG or WebP for screenshots.
- Add short captions in adjacent markdown files if you need extra context.

## Note

The `demo/` folder is for documentation assets only. It is not served by the application at runtime.
